GankStore / Cara Beli

Cara Beli

Semua transaksi selesai di dalam toko ini — tanpa aplikasi lain. Pilih akun, buat pesanan, invoice langsung terbit, lalu bayar lewat Midtrans. Ikuti tiga langkah ini.

01

Pilih akun di Katalog

Telusuri halaman Katalog, lalu buka halaman Detail Akun untuk melihat rank, level, server, dan isi akun Point Blank-nya secara lengkap.

02

Klik Beli Sekarang, invoice terbit

Tekan tombol Beli Sekarang — akunnya otomatis ditandai Dipesan atas namamu dan kamu langsung dibawa ke halaman Invoice di toko ini. Invoice berisi nomor invoice, harga akun, biaya admin, dan total bayar.

03

Bayar via Midtrans & terima data akun

Bayar total di invoice lewat Midtrans (QRIS, e-wallet, atau virtual account). Setelah pembayaran dikonfirmasi lunas oleh admin, status invoice berubah jadi Lunas dan data login akun diserahkan ke kamu. Segera ganti password dan amankan akun setelah diterima.

Yang perlu dicek sebelum bayar

  • Rank, level, dan server sudah sesuai yang kamu cari.
  • Isi akun (senjata, char, item) sesuai daftar di halaman detail.
  • Status akun masih “Tersedia”, bukan “Terjual”.
  • Total di invoice sudah benar: harga akun + biaya admin 10%.

Biaya admin & pembayaran

  • Biaya admin = 10% dari harga akun. Contoh: akun Rp1.000, biaya adminnya Rp100, total bayar Rp1.100 — dan seterusnya mengikuti harga akun.
  • Biaya admin selalu tampil sebagai baris terpisah di invoice, tidak disembunyikan.
  • Pembayaran diproses lewat Midtrans: QRIS, e-wallet, dan virtual account bank.
  • Simpan nomor invoice-mu — itu bukti pesananmu di toko ini.

Cara Top Up (All Game)

  • Buka halaman Top Up, pilih game-nya.
  • Pilih paket (diamond / UC / Genesis Crystal / dll), isi User ID — plus Server / Zone ID bila gamenya butuh.
  • Klik Buat Pesanan & Invoice — totalnya harga paket + biaya admin 10%.
  • Bayar invoice lewat Midtrans, lalu admin memproses top up ke User ID-mu dan menandai Selesai.

Jujur soal top up

  • Top up diproses manual oleh admin setelah pembayaran lunas — belum ada pengiriman otomatis ke akun game.
  • Pastikan User ID benar. Salah ID berarti top up terkirim ke akun lain dan tidak bisa ditarik lagi.
  • Status pesanan top up bisa dicek di Pesanan Saya, sama seperti pembelian akun.

Tanya Jawab

Apakah akunnya stok milik penjual sendiri?

Ya. GankStore adalah toko dengan stok milik penjual sendiri, dan saat ini fokus khusus menjual akun Point Blank — bukan marketplace dari banyak penjual.

Bagaimana cara membayarnya?

Klik Beli Sekarang pada akun yang dipilih, invoice langsung terbit di toko ini. Bayar totalnya (harga akun + biaya admin 10%) lewat Midtrans dengan QRIS, e-wallet, atau virtual account.

Berapa biaya adminnya?

Biaya admin adalah 10% dari harga akun, dibulatkan ke rupiah terdekat. Contoh: harga Rp100.000, biaya admin Rp10.000, total bayar Rp110.000. Rinciannya selalu tertulis di invoice sebelum kamu membayar.

Akun yang saya mau sudah terjual, bagaimana?

Akun berlabel TERJUAL sudah tidak bisa dibeli. Cek akun lain yang tersedia di Katalog.

Kapan data akun saya terima?

Setelah pembayaranmu dikonfirmasi lunas, admin menandai pesanan sebagai Terjual dan status invoice-mu berubah jadi Lunas. Di invoice itu muncul tombol ke halaman sukses, tempat email & password akun ditampilkan satu kali — salin dan simpan saat itu juga, karena setelah ditampilkan data tersebut otomatis dihapus dari toko dan tidak bisa dilihat lagi.

    Jujur soal top up

    • Top up diproses manual oleh admin setelah pembayaran lunas — belum ada pengiriman diamond / UC otomatis ke akun game, karena belum ada supplier / provider top up.

    • Biaya admin 10% berlaku sama seperti pembelian akun dan selalu tertulis di invoice.
